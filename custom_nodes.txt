# Custom node packages, installed at build time.  name  owner/repo  ref
#
# Third-party packages are pinned to a commit. They used to say `HEAD`, which
# is not a ref GitHub's tarball endpoint resolves the way git does: on the 17
# Oct build it handed back rgthree's `dev` branch, untouched since Nov 2023,
# whose import patches a ComfyUI function that no longer exists. rgthree failed
# to load, the Power Lora Loader every v8-v10 graph uses went with it, and the
# whole night run was rejected at validation. To move one forward: take the sha
# from `git ls-remote https://github.com/<repo> refs/heads/<branch>`, change it
# here, and render a test job before the night run does.
#
# Our own packages (rvspromotion-glitch/*) follow `main` by name, so a merged
# fix reaches the next build without a bump here. CI passes NODES_REFRESH so
# that step is never served from cache.
#
# install_nodes.sh refuses `HEAD`, and fails the build if a pinned sha is not
# what the download contains.
#

# rest are core ComfyUI. verify_nodes.py prints which package supplied which
# node and which packages supplied nothing — trim this list from that output
# rather than from guesswork.
