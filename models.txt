# Shared models, fetched at container start. One per line:
#
#   hf     <repo>  <path-in-repo>       <dest under MODELS_DIR>
#   civit  <url>                        <dest under MODELS_DIR>
#
# Only what the four graphs actually load. v1 renders from the all-in-one
# checkpoint; v2 renders from the raw model plus the turbo LoRA. Both sets are
# fetched because either version can be selected per job.
#
# These are NOT baked into the image. ~39GB of models plus torch does not build
# on a hosted GitHub runner, so the image carries ComfyUI and the code and the
# worker fetches the weights on cold start. Skip-if-present, so a warm worker
# and a restarted container pay nothing.
#
# Destination filenames are what the graphs reference — renaming one here
# without renaming it in workflows/*.json breaks the render, not the download.
